Paran Recorder 개발 테스트 방법
=================================

처음 한 번
----------
1. 저장소를 Git으로 clone합니다.
2. 저장소 폴더에서 SETUP_DEV.bat를 더블클릭합니다.
3. 모든 항목이 [OK]로 나오면 준비 완료입니다.

이후 테스트
-----------
RUN_LATEST.bat만 더블클릭합니다.

자동으로 하는 일:
1. GitHub main 브랜치의 최신 소스를 받습니다.
2. npm 패키지를 확인합니다.
3. Tauri 개발판을 실행합니다.

개발판 특징
-----------
- 설치 파일을 새로 만들지 않고 바로 실행합니다.
- HTML/CSS/JavaScript 수정은 개발 중 자동 반영됩니다.
- Rust 수정은 Tauri가 자동 재컴파일합니다.
- RVM 모델은 RVM Native HQ를 처음 선택할 때 앱이 자동 다운로드합니다.
- 프로그램을 종료한 뒤 콘솔에서 Ctrl+C를 누르면 개발 서버도 종료됩니다.

주의
----
- 로컬 소스가 직접 수정되어 있으면 RUN_LATEST.bat는 자동 업데이트를 중단합니다.
  작업 내용이 GitHub 변경으로 덮이는 것을 방지하기 위한 것입니다.
- Rust 컴파일 오류가 나면서 MSVC/Linker 관련 메시지가 나오면
  Visual Studio Build Tools의 'Desktop development with C++' 워크로드가 필요합니다.
- Microsoft Edge WebView2 Runtime이 필요합니다. 최신 Edge가 설치된 Windows에는 보통 함께 설치되어 있습니다.

최종 배포
---------
개발 중에는 RUN_LATEST.bat만 사용합니다.
설치판/포터블 EXE는 기능이 충분히 안정된 뒤 최종 단계에서만 빌드합니다.
