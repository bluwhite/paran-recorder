# Native resources

The Windows native build uses the Apache-2.0 MODNet ONNX model.

The model is not committed to Git. Run:

```bash
npm run native:model
```

This downloads and verifies:

`resources/models/modnet.onnx`

Source:
`Xenova/modnet / onnx/model.onnx`

Expected size: 25,888,640 bytes  
Expected SHA256: `07c308cf0fc7e6e8b2065a12ed7fc07e1de8febb7dc7839d7b7f15dd66584df9`

The Windows build also gathers ONNX Runtime / DirectML DLLs generated by the Rust
`ort` dependency. GitHub Actions packages them with the install-free test ZIP
and with the NSIS build resources.
